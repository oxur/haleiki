# Template Conversion Plan — HTML Mockups to Cobalt/Liquid

**Version:** 1.0
**Depends on:** All mockups complete (07–15), demo pipeline (Phases 1–5), search plan
**Produces:** Working Cobalt site with all page types rendering from Liquid templates

---

## Overview

Convert 9 self-contained HTML mockups into a Cobalt static site project with shared CSS, Liquid templates, and the `_data/` JSON contract. This is the bridge from "designed pages" to "working wiki."

---

## Content Model — Three Lanes

| Lane | Directory | Cobalt Type | Iterated Via | Layout |
|------|-----------|-------------|-------------|--------|
| **Sources** | `content/sources/` | Pages | `site.data.sources` | `source.liquid` |
| **Concepts** | `content/concepts/` | Pages | `site.data.concepts` | `concept.liquid` |
| **News** | `posts/` | Posts | `collection.posts` | `post.liquid` |
| **Static pages** | root / `pages/` | Pages | Not iterated | Various (`home`, `page`, `search`, etc.) |

- Sources and concepts are **Cobalt pages** with `layout:` in their frontmatter
- News/updates use Cobalt's native **posts** collection (gets RSS, chronological ordering, pagination for free)
- Static pages (home, attribution, about, search, browse) are individual pages with their own layouts
- All listing/browsing/category views are powered by `_data/` JSON generated by the Rust CLI

## CSS Extraction

### Shared CSS: `assets/css/haleiki.css`

Extract from the mockups into a single file with cascade layers:

```css
@layer tokens, reset, base, layout, components, utilities;

@layer tokens { /* ~160 lines — identical in all mockups */
  :root { /* scale, spacing, type families, layout vars */ }
  [data-theme="day"] { /* day theme tokens + footer tokens */ }
  [data-theme="night"] { /* night theme tokens + footer tokens */ }
}

@layer reset { /* ~25 lines */ }

@layer layout { /* ~350 lines */
  /* Topnav */
  /* Page layout (three-col, two-col variants) */
  /* Left nav / TOC */
  /* Content area + sidebar */
  /* Footer layout */
}

@layer components { /* ~500 lines */
  /* Prose (headings, paragraphs, links, lists, code) */
  /* Code block */
  /* Callout */
  /* Info card (taxonomy sidebar) */
  /* See-also grid */
  /* Tags */
  /* Breadcrumb */
  /* Search input */
  /* Theme toggle */
  /* Footer columns */
}

@layer utilities { /* ~15 lines */
  /* Left nav hide at 60rem */
  /* Footer wrap at 40rem */
}
```

## `_cobalt.yml` Configuration

```yaml
# Haleiki site configuration

site:
  title: "Haleiki"
  description: "House of Knowledge — a read-only wiki for structured knowledge"
  base_url: "https://oxur.github.io/haleiki"

# News/updates collection (Cobalt's native posts)
posts:
  title: "Haleiki News"
  description: "Updates, announcements, and development notes"
  dir: "posts"
  drafts_dir: "_drafts"
  order: Desc
  rss: "news/feed.xml"
  jsonfeed: "news/feed.json"
  publish_date_in_filename: true
  default:
    layout: "post.liquid"
    permalink: "/news/{{year}}/{{month}}/{{slug}}"

# Default frontmatter for all pages
default:
  excerpt_separator: "\n\n"

# Syntax highlighting
syntax_highlight:
  theme: "base16-ocean.dark"
  enabled: true

# Template extensions
template_extensions:
  - liquid
  - md

# Asset processing
assets:
  sass:
    style: Compressed
```

## Template Details

### `default.liquid` — Base Shell

```liquid
<!DOCTYPE html>
<html lang="en" data-theme="day">
<head>
  {% include "head.liquid" %}
</head>
<body>
  {% include "topnav.liquid" %}

  {{ page.content }}

  {% include "footer.liquid" %}
  {% include "scripts.liquid" %}
</body>
</html>
```

### `source.liquid` — Three-Column Article

```liquid
---
layout: default.liquid
---
<div class="page-layout">
  <aside class="left-nav">
    {% include "sidebar-toc.liquid" %}
  </aside>

  <div class="content-area">
    <main class="article" data-pagefind-body>
      {% include "breadcrumb.liquid" %}
      <header class="article-header">
        <div class="article-overline"
             data-pagefind-filter="type">Source</div>
        <h1 class="article-title"
            data-pagefind-meta="title">{{ page.title }}</h1>
        <p class="article-subtitle">{{ page.data.subtitle }}</p>
        <div class="article-meta">
          <span data-pagefind-filter="category"
                data-pagefind-meta="category">{{ page.data.category }}</span>
          <span data-pagefind-filter="tier">{{ page.data.tier }}</span>
          {% for tag in page.data.tags %}
            <a href="#" class="tag">{{ tag }}</a>
          {% endfor %}
        </div>
      </header>

      <div class="prose">
        {{ page.content }}
      </div>

      {% include "see-also.liquid" %}
    </main>

    <aside class="sidebar">
      {% include "sidebar-taxonomy.liquid" %}
    </aside>
  </div>
</div>
```

### `home.liquid` — Front Page

```liquid
---
layout: default.liquid
---
<main class="home-content">
  <!-- Hero with search -->
  <section class="home-hero">
    <div class="home-brand-mark">H</div>
    <h1 class="home-title">Haleiki</h1>
    <p class="home-subtitle"><em>House of Knowledge</em></p>
    <!-- Large search input -->
    <div class="home-search">
      <input type="text" placeholder="Search {{ site.data.sources | size }} articles...">
    </div>
  </section>

  <!-- Category grid — driven by _data/categories.json -->
  <section class="home-categories">
    <h2>Explore by Category</h2>
    <div class="category-grid">
      {% for cat in site.data.categories %}
        <a href="/categories/{{ cat.slug }}/" class="category-card">
          <h3>{{ cat.name }}</h3>
          <span class="count">{{ cat.article_count }} articles</span>
          <p>{{ cat.description }}</p>
        </a>
      {% endfor %}
    </div>
  </section>

  <!-- News preview — latest post from the posts collection -->
  <section class="home-news">
    {% for post in collection.posts limit:1 %}
      <a href="/{{ post.permalink }}">{{ post.title }}</a>
    {% endfor %}
  </section>
</main>
```

### `category.liquid` — Category Listing

```liquid
---
layout: default.liquid
---
<div class="page-layout">
  <main class="main-content">
    {% include "breadcrumb.liquid" %}
    <header>
      <div class="overline">CATEGORY</div>
      <h1>{{ page.title }}</h1>
      <p>{{ page.data.description }}</p>
    </header>

    <!-- Articles grouped by tier — data from _data/categories.json -->
    {% assign cat = site.data.categories | where: "slug", page.data.category_slug | first %}
    {% for tier in cat.tiers %}
      <section class="tier-section">
        <h2>{{ tier.name }}</h2>
        {% for article in tier.articles %}
          <a href="{{ article.url }}" class="article-item">
            <span class="article-title">{{ article.title }}</span>
            <span class="article-tier">{{ article.tier }}</span>
          </a>
        {% endfor %}
      </section>
    {% endfor %}
  </main>

  <aside class="sidebar">
    {% include "sidebar-taxonomy.liquid" %}
  </aside>
</div>
```

## Pagefind Integration

### Template attributes (added during conversion):

```html
<!-- On source.liquid and concept.liquid -->
<main data-pagefind-body>

<!-- Metadata -->
<h1 data-pagefind-meta="title">{{ page.title }}</h1>

<!-- Filters -->
<span data-pagefind-filter="category">{{ page.data.category }}</span>
<span data-pagefind-filter="tier">{{ page.data.tier }}</span>
<span data-pagefind-filter="type">{{ page.data.page_type }}</span>
```

### Build step:
```bash
haleiki build            # Generate _data/ JSON
cobalt build             # Render HTML from Liquid templates
npx pagefind --site _site  # Index rendered HTML for search
```
