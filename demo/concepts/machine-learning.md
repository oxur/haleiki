## Quick Definition

Machine learning is the study of programs that can improve their performance on a given task automatically, using techniques such as supervised learning, unsupervised learning, and reinforcement learning. It has been a part of AI from the beginning.

## Core Definition

Machine learning is the study of programs that can improve their performance on a given task automatically. It has been a part of AI from the beginning ([artificial-intelligence](/source/artificial-intelligence/)). There are several kinds: unsupervised learning analyzes data and finds patterns without guidance; supervised learning requires labeled training data and comes in classification and regression varieties; reinforcement learning rewards good responses and punishes bad ones ([artificial-intelligence](/source/artificial-intelligence/)). Deep learning is a type of machine learning that runs inputs through biologically inspired artificial neural networks ([artificial-intelligence](/source/artificial-intelligence/)).

## Key Properties

1. **Unsupervised learning** -- finds patterns in data without labels ([artificial-intelligence](/source/artificial-intelligence/)).
2. **Supervised learning** -- requires labeled data; includes classification and regression ([artificial-intelligence](/source/artificial-intelligence/)).
3. **Reinforcement learning** -- learns from rewards and punishments ([artificial-intelligence](/source/artificial-intelligence/)).
4. **Transfer learning** -- applies knowledge from one problem to new problems ([artificial-intelligence](/source/artificial-intelligence/)).
5. **Foundational to modern AI** -- has been part of AI since its beginning and underpins most current AI systems ([artificial-intelligence](/source/artificial-intelligence/)).
