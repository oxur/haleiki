## Quick Definition

An abugida is a type of alphabet where each symbol represents a consonant-vowel pair with an inherent default vowel, and other vowels are indicated by predictable modifications to the base symbol. The Brahmic family of scripts is the largest group of abugidas.

## Core Definition

An abugida is a type of alphabet with symbols corresponding to consonant-vowel pairs, where basic symbols for each consonant are associated with an inherent vowel by default, and other possible vowels are indicated via predictable modifications. The largest single group of abugidas is the Brahmic family of scripts, which includes nearly all the scripts used in India and Southeast Asia ([writing-system](/source/writing-system/)). Kharosthi is an example of an abugida, derived from the Aramaic alphabet with extensive modifications to represent the phonology of Gandhari Prakrit and other languages ([kharosthi](/source/kharosthi/)).

## Prerequisites

- **Alphabet** -- abugidas are a subtype of alphabetic writing systems.

## Key Properties

1. **Inherent vowel** -- each consonant symbol carries a default vowel (typically /a/).
2. **Predictable vowel modification** -- non-default vowels are indicated by diacritics or modifications applied consistently across consonants.
3. **Brahmic family** -- the largest group, covering Devanagari, Tibetan, Thai, Burmese, and many others.
4. **Origin from abjads** -- most abugidas originated from abjads with added vowel markings.

## Context & Application

The name "abugida" was derived by linguist Peter T. Daniels from the first four characters of the Ge'ez script (Ethiopian/Eritrean). The Tibetan script used for Classical Tibetan is a Brahmic abugida. Kharosthi is an abugida that unusually writes right-to-left, unlike most Indic scripts ([writing-system](/source/writing-system/), [kharosthi](/source/kharosthi/)).

## Examples

**Example 1** ([writing-system](/source/writing-system/)): In an abugida, there may be a sign for _k_ with no vowel, _ka_ (with inherent vowel), and _ke_ formed by modifying _ka_ consistently with how _la_ becomes _le_.

## Relationships

- **Prerequisite: alphabet** -- abugidas are a type of alphabet.
- **Extends: alphabet** -- adds the inherent-vowel mechanism.
- **Related to kharosthi** -- Kharosthi is an abugida.
- **Contrasts with abjad** -- abjads write only consonants; abugidas write consonant-vowel pairs.
