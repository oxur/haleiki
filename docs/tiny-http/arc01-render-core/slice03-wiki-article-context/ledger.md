## What Worked

- Reading `graph.rs`'s edge-resolution rules (`resolve_url_by_edge`'s
  concept-first logic) *before* writing F-3's test, then predicting exactly
  which real demo slugs would resolve to a source vs. a concept URL
  (`abelian-group`'s `prerequisite`/`extends` → the source
  `group-mathematics`, because no concept card shares that slug), let the
  test assert real, specific, falsifiable values instead of just "the map is
  non-empty." All four predictions matched on the first run — the kind of
  test that would actually catch a resolution-rule regression.
- Building `SiteContext` and `assemble_site_context` in `render.rs` (rather
  than a new module) and `page.data` assembly + the render pipeline in a
  fresh `article.rs` kept a clean seam: "site-wide, reused by every future
  page type" vs. "per-article-type." The site.data wrapping bug this
  produced (`site => site` instead of `site => context!{ data => site }`,
  caught by an `UndefinedError` on the very first render test) is exactly
  the kind of contract mismatch this seam was designed to make loud rather
  than silent.
- Extracting `build_provenance_map` out of `write_provenance_json` with the
  existing `test_provenance_json_bidirectional` test as a regression guard
  (assert the JSON output first, refactor, rerun) verified the extraction
  was behavior-preserving without having to reason about it by inspection
  alone.
- Running `cargo clippy --all-targets` (not just `--all-features`) as this
  slice's own F-9 discipline — per the explicit slice-02 lesson — surfaced a
  real, previously-invisible category of pre-existing debt (28 findings,
  entirely outside this slice's own code) before it could be mistaken for
  "clean" the way slice 02's `--all-targets` gap once was.
- The self-referential `include_str!` grep bug in the F-8 test (the
  assertion's own literal string matched itself) was caught immediately by
  running the test rather than assuming a grep-shaped check is
  self-evidently correct — worth remembering for any future "does the source
  avoid X" test written this way.
